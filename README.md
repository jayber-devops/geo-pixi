# geo-pixi

[Pixi](https://pixi.prefix.dev) environments for geospatial operations

## Usage

- [Install Pixi](https://pixi.prefix.dev/latest/installation/)
- Navigate to the directory containing your desired environment
- `pixi shell` or `pixi shell -e NAME_OF_ENVIRONMENT`
  - See pixi.toml for list of available environments
  - Default environment is typically installed with a more permissive usage scheme (i.e. using conda-forge and pypi), although some packages may still be proprietary.
